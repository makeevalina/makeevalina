## Кейс: «Европейское художественное наследие XIX–XX веков» (Продуктовая доработка курсовой работы)

**Задача:** Превратить статичную базу данных о художниках и картинах в аналитический инструмент для принятия решений (аналог продуктовой аналитики)

### Базовая часть (учебный проект)

Спроектировала и реализовала реляционную базу данных в PostgreSQL:

- **Схема:** 5 таблиц (художники, картины, музеи, направления, связь М:М)
- **Целостность:** Реализованы ограничения (первичные/внешние ключи, CHECK, UNIQUE)
- **Анализ:** Написана серия из 10 SQL-запросов базового уровня для извлечения данных

### Самостоятельная доработка (Продуктовая аналитика)

Добавила 5 продвинутых аналитических запросов, моделируя реальные бизнес-задачи:

1. **Воронка «художник → создание картины → выставление»** *(аналог: регистрация → создание контента → публикация)*  

2. **RFM-сегментация художников** *(аналог: сегментация пользователей по выручке и активности)*  
   Разделила художников на 4 группы: **VIP, High value, Regular, Newbie** — по частоте создания картин и их стоимости

3. **Когортный анализ по векам рождения** *(аналог: удержание когорт пользователей)*  
   Сравнила продуктивность художников разных эпох (количество картин на одного художника в когорте 50 лет)

4. **Эффективность музеев** *(аналог: эффективность каналов привлечения)*  
   Посчитала «конверсию» музеев: долю картин, находящихся на выставке

5. **Выявление аномально дорогих картин** *(аналог: выявление выбросов в метриках)*  
   Использовала **Z-score** (`> 2`) для поиска картин с аномально высокой стоимостью

### A/B‑тест: стоимость картин по направлениям

**Гипотеза:** Средняя стоимость картин импрессионистов выше, чем у постимпрессионистов.  
**Метод:** U‑тест Манна‑Уитни.  
**Вывод:** Статистически значимой разницы нет (`p‑value > 0.05`).  

[Отчёт по A/B‑тесту](ссылка_на_jupyter_notebook)
