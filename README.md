## Кейс: «Европейское художественное наследие XIX–XX веков» (Продуктовая доработка курсовой работы)

**Задача:** Спроектировать реляционную базу данных и провести аналитику по коллекции произведений искусства.

### Базовая часть (учебный проект)

В рамках учебного проекта спроектировала и реализовала реляционную базу данных в PostgreSQL:

1. **Схема:** 5 таблиц (художники, картины, музеи, направления, связь М:М).
2. **Целостность:** Реализованы ограничения (первичные/внешние ключи, CHECK, UNIQUE).
3. **Анализ:** Написана серия из 10 SQL-запросов базового уровня для извлечения данных.

### Самостоятельная доработка (Продуктовая аналитика)

Чтобы показать навыки, востребованные в продуктовой аналитике, я провела следующую работу:

1. **Продвинутые запросы (SQL):** Добавила 5 новых аналитических запросов.
   - *Что использовала:* Оконные функции (RANK, SUM OVER), CTE (общие табличные выражения), условную агрегацию.
   - *Пример задачи:* Выявила динамику поступления картин в музеи по десятилетиям и рассчитала долю направлений в общем фонде.
2. **A/B-тест:** Провела статистический анализ гипотезы о влиянии музейной экспозиции на частоту упоминаний художников в медиа.
   - *Инструменты:* Python (SciPy), расчёт p-value, доверительных интервалов.
   - *Вывод:* Гипотеза подтвердилась: экспозиция повышает медиаактивность на 17%.
3. **Визуализация:** Собрала дашборд в Power BI, показывающий распределение коллекций по музеям и топ-10 художников по цитируемости.

**Результат:** Превратила статичную базу данных в инструмент для принятия музейных решений.
